添加新作品

教程：3 步发布新内容到作品集

← 返回首页

本作品集是纯静态 + 数据驱动架构。所有内容从 data/*.json 读取，添加新作品/文章/相册只需要 3 步：上传文件 → 编辑 JSON → 推送到 GitHub。

1

上传文件到云存储

把图片、视频、文档、PDF 上传到云存储（推荐七牛云/又拍云，国内访问快）。

详细配置步骤见 UPLOAD-GUIDE.md。

📁 推荐云存储：
  • 七牛云（每月 10GB 免费）
  • 又拍云（每月 15GB 免费）
  • 腾讯云 COS / 阿里云 OSS
2

编辑对应的 JSON 数据

在 data/ 目录下编辑对应类型的 JSON 文件，添加新内容。

JSON 文件路径和示例：

data/works.json      # 作品
data/articles.json   # 文章
data/albums.json     # 相册
data/videos.json     # 视频
data/documents.json  # 文档
data/presentations.json  # PPT
3

提交到 GitHub

本地预览后，提交代码到 GitHub，自动部署到 GitHub Pages。

git add .
git commit -m "添加新作品: product-redesign"
git push origin main

推送后 1-2 分钟内网站自动更新。

文件命名规范

📂 推荐目录结构： 
assets/images/works/{work-id}/cover.jpg      # 作品封面
assets/images/works/{work-id}/01.jpg         # 作品配图
assets/images/albums/{album-id}/01.jpg       # 相册照片
assets/images/articles/{article-id}/cover.jpg  # 文章封面
assets/images/videos/{video-id}/cover.jpg    # 视频封面
  • 使用小写字母 + 数字 + 连字符（kebab-case）
  • 图片优先使用 WebP 或压缩后的 JPG（< 200KB）
  • 不使用中文文件名（避免编码问题）

本地预览

由于使用了 fetch() 加载 JSON，必须用 HTTP 服务器预览，不能直接双击 HTML。

# Python 3
python -m http.server 8000

# Node.js
npx serve .

# VS Code
安装 Live Server 插件，右键 → Open with Live Server

然后浏览器打开 http://localhost:8000。
